# 连续合约市场断代分段设计

## 背景与目标

国信连续信号面板按新旧主力合约的共同收盘价计算后复权因子。真实数据中，燃料油
`FU1804.SHF` 最后交易日为 2018-03-30，`FU1901.SHF` 首日为 2018-07-16；两张合约
没有共同交易日，因此不存在可观察的复权比率。

目标是在不伪造价格的前提下继续构建全历史面板，并让后续 EMA、ATR、TNR 与 U2P
明确知道连续序列已经断开。

## 裁决

采用显式连续分段：新旧主力的全部有效收盘日期区间严格不相交，且旧合约最后收盘日
早于新合约最早收盘日时，新合约开启该品种的下一连续段。新段复权因子从 1.0 重新
开始，`continuity_segment` 从 0 起逐次加一。

这项裁决只处理可证明的市场断代，不放宽普通换月的数据完整性要求：

- 新旧合约存在共同收盘日时，仍使用换月判定日之前最近的共同收盘价计算复权比率。
- 两张合约的收盘日期区间有重叠、但找不到共同有效收盘日时，继续以
  `roll_close_missing` 硬失败；这更像数据缺失，不能当成市场断代。
- 任一合约完全没有有效收盘价时同样硬失败。
- 不使用常数、前后单边价格、理论价或人工阈值拼接两个不可比的价格区间。

## 数据模型与流向

`adjustment_factors` 在每个品种内维护 `adj_factor` 和 `continuity_segment`：

1. 品种第一条主力记录使用因子 1.0、分段 0。
2. 合约不变时，两者保持不变。
3. 正常换月时，用最近共同收盘价累乘因子，分段不变。
4. 确认市场断代时，分段加一，因子重置为 1.0。

因子表新增 `continuity_segment`。面板构建器要求调用方同时提供每个
`(trade_date, product)` 的因子和分段，输出 Parquet 也新增同名 `int64` 列。缺少任一
映射时 fail-closed，不默认为 0。

全历史主力链仍在月度分片之前一次性计算，因此相同历史窗口的分段编号跨月稳定；已有
月份分片的断点续跑语义不变。

## 下游约束

任何价格型状态都不得跨 `continuity_segment` 延续。后续回测实现必须至少按
`(product, continuity_segment)` 分组计算 EMA、ATR、TNR 和 U2P，并在新段重新满足
各自预热期后才能发信号。成交仍使用未复权真实价格，不受段内复权因子尺度影响。

报告需披露各品种的分段次数与分段首日，使市场断代不会被误读为普通换月或策略空仓。

## 运行审计与错误处理

面板脚本在全历史主力/因子摘要中打印连续段总数与断代数。普通缺价仍输出结构化的
`roll_close_missing`，其中包含旧、新合约和换月判定日；断代不是警告后继续拼接，而是
通过面板列永久保留其边界。

## 验收测试

- 新旧合约日期区间完全分离时，新合约因子为 1.0 且分段从 0 增至 1。
- 存在多个共同收盘日时，选择判定日前最近一天，不选择更早日期。
- 日期区间重叠但没有共同有效收盘日时仍报 `roll_close_missing`。
- CZCE 三位/四位代码别名不制造虚假换月或分段。
- 面板逐品种日携带正确分段；缺少分段映射时拒绝构建。
- `continuity_segment` 以 `int64` 完成 Parquet 往返。
- 相关测试完成手工变异验证，并在实现后运行全量测试。

## 非目标

本设计不决定回测参数、不修改会话规则资产、不填补缺失日线，也不为没有市场价格的
停牌区间估计收益率。
