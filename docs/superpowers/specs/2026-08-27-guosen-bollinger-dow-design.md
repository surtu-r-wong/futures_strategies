1. 国信证券《CTA 系列专题之二：基于 Bollinger 通道的商品期货交易策略》
   （研报日期 2021-10-13，公众号日期 2021-10-14）
2. 国信证券《CTA 系列专题之四：基于道氏理论的商品期货交易策略》

## 1. 目标与非目标

目标是分别完成两篇研报的忠实策略复刻，并给出研报样本之外的检验。每个策略都要有：

- 可审计的 15 分钟信号与具体合约成交；
- 命令行入口、单元测试、集成测试和全历史回测；
- Excel、净值图和 JSON 审计产物；
- 研报口径、研报沉默处裁决、数据降级和复刻指标差异的保真度台账；
- 严格分开的样本内和样本外结果。

两个策略独立运行、独立分配资金、独立报告。不会构造两者之间的等权组合，也不会复刻研报中包含开盘动量、Carry 等其他策略的 CTA 复合组合。

## 2. 设计原则

### 2.1 共享基础设施，隔离策略语义

成交额宇宙、商品主力、后复权、15 分钟面板、影子品种筛选和事件账户属于商品期货复刻的共同机器，应落在 `common/commodity/`。Bollinger、道氏和正在建设的连续信号策略只保留自己的指标、状态机、参数和报告扩展。

现有 `cta_continuous` 不应成为其他策略的基础包。迁移共享代码时保留兼容再导出，并用迁移前后的 DataFrame 内容摘要和既有测试证明行为不变。

### 2.2 信号连续价与真实成交价分离

指标和信号使用后复权的主力连续 OHLC。实际成交价、合约手数、持仓市值和换月交易使用具体合约的真实价格。任何使用连续价计算真实下单数量的路径均视为错误。

### 2.3 所有历史选择保持因果

- 用前一交易日的成交量和持仓量选择当日主力；
- 当月宇宙只使用上月末以前的数据；
- 当月动态品种筛选和波动率系数只使用上月末以前的策略表现；
- 样本外不得参与参数或口径选择。

### 2.4 研报沉默处显式裁决

未披露参数或执行细节不得以“常见做法”静默填充。默认裁决、依据和敏感性变体必须进入 `fidelity` 工作表。变体只用于解释复刻差异，不用于事后挑选最好结果。

## 4. 共享市场口径

### 4.1 流动性宇宙

投资标的是过去六个月品种级日均成交额不少于 50 亿元的商品期货：

- 每个自然月更新一次；
- 窗口为 `[month_start - 6 months, month_start)`；
- 分子为品种全部具体合约成交额之和，不只统计主力；
- 分母为窗口内全市场交易日数，品种缺席日按零成交额处理；
- 排除 IF、IC、IH、IM、T、TF、TL、TS；
- 郑商所历史三位与四位交割码孪生记录先归一、验值、去重；
- 当月数据绝不参与当月宇宙。

### 4.2 主力合约

商品主力必须同时达到当日品种内最大成交量和最大持仓量，并满足：

- 用前一交易日数据选当日合约；
- 交割年月不可倒退；
- 双最大不成立时沿用上一主力；
- 无上一主力且双最大不成立时，当日不生成可交易主力；
- 郑商所交割码在比较月份前归一；
- 与 `continuous_contract_ohlc.contract_used` 的重叠区间只对账，不用参照表改写自选结果。

### 4.3 后复权

基期为 2010-01-01，初始因子为 1。主力由旧合约切换到新合约时：

```text
AdjFactor_i = AdjFactor_(i-1)
              * Close_(i-1, old)
              / Close_(i-1, new)
```

新主力的 O/H/L/C 全部乘当期因子。缺少展期前一交易日任一合约收盘价时失败，不以 1 填充。

### 4.4 十五分钟面板与成交

- 严格按品种、日期和版本化交易时段构造 15 分钟桶；
- 无成交 bar 保留在全局时间栅格，但不进入指标、ATR 或 OI 均线；
- 非交易时段行情为空、信号延续、策略收益为零；
- 尚未上市时行情和收益为空，不允许发信号；
- 信号在 15 分钟 bar 收盘后确定；
- 成交价为随后五个交易分钟的 `sum(amount) / (sum(volume) * multiplier)`；
- 信号落在时段最后一根 bar 时，顺延到下一交易时段前五分钟；
- 郑商所合成 `amount` 使用既有定价基准资产中的 OHLC typical price，并逐笔标记；
- 应成交窗口无法定价时，忠实模式失败，不虚构价格。

## 5. Bollinger 策略

### 5.1 指标

只在有成交的 15 分钟后复权 bar 上计算：

```text
Middle_t = mean(Close, 300)
Std_t    = std(Close, 300, ddof=0)
Upper_t  = Middle_t + 1.5 * Std_t
Lower_t  = Middle_t - 1.5 * Std_t

OI_short_t = mean(OI, 150)
OI_long_t  = mean(OI, 300)
```

标准差自由度研报未披露。忠实默认预注册为 `ddof=0`，另跑 `ddof=1` 敏感性对照。ATR 周期也未披露，默认预注册为有成交 15 分钟 bar 的 20 期简单移动平均。

### 5.2 交易状态机

空仓时：

- 前收不高于上轨且当前收盘高于上轨，触发多头开仓；
- 前收不低于下轨且当前收盘低于下轨，触发空头开仓；
- 指标历史不足 300 根时不允许开仓。

持有多仓时，以下任一条件触发平仓：

- 当前收盘下穿中轨；
- 当前收盘首次达到或超过固定多头止盈线。

空仓完全对称。止盈线在开仓信号 bar 冻结：

```text
LongTakeProfit  = Middle_entry + 8 * Std_entry
ShortTakeProfit = Middle_entry - 8 * Std_entry
```

止盈后必须等待新的上下轨穿越事件；价格仍停留在通道外时不原地重开。

### 5.3 持仓量倍率

开仓信号 bar 上：

- `OI_short > OI_long`：倍率 1.0；
- 否则：倍率 0.5。

倍率随该笔交易冻结，不因持仓期间 OI 变化而调整。

### 5.4 品种筛选

所有具有足够行情历史的商品品种均运行不受实际选中状态影响的影子策略。月末对当前满足流动性条件的品种检查此前 252 个交易日：

- 完成交易少于 5 笔：剔除；
- 完成交易不少于 5 笔，且 Sharpe 与 Calmar 同时小于 0：剔除；
- 其余保留。

影子收益包含 ATR 杠杆、OI 倍率和 1.3 bp 单边成本，但不包含组合级已实现波动率调整。这样保持研报“信号过滤及止盈 -> 品种筛选 -> 组合波动调整”的先后顺序。

### 5.5 资金和杠杆

```text
Lev_ATR = clip(0.005 * real_close / ATR20, 0, 4)
Mul_vol = 0.10 / portfolio_realized_vol_252d
Lev     = clip(Lev_ATR * Mul_vol, 0, 4)
Target  = direction * selected_universe_weight
          * OI_multiplier * Lev
```

`Mul_vol` 在月末计算并在下月保持不变。资金在当月全部入选品种间等分；无持仓品种的份额留作现金，不转配给当时有信号的品种。

### 5.6 样本

- 研报忠实样本：2012-01-04 至 2021-09-30；
- 样本外：2021-10-01 至可靠数据上界，当前为 2026-01-30；
- 研报对照：年化收益 17.52%、Sharpe 1.72、最大回撤 8.27%、Calmar 2.12、年化波动 10.16%。

## 6. 道氏策略

### 6.1 MACD 累计穿越

只在有成交的 15 分钟后复权 bar 上计算：

```text
Fast_t       = EMA(Close, 12, adjust=False)
Slow_t       = EMA(Close, 26, adjust=False)
MACD_t       = Fast_t - Slow_t
SignalLine_t = EMA(MACD, 9, adjust=False)
Diff_t       = MACD_t - SignalLine_t
```

累计穿越距离为：

```text
if Diff_t * Diff_(t-1) < 0:
    CumMACD_t = Diff_t
else:
    CumMACD_t = CumMACD_(t-1) + Diff_t
```

初步趋势状态为：

- `CumMACD >= ATR20`：切换为上升趋势；
- `CumMACD <= -ATR20`：切换为下降趋势；
- 两阈值之间保持已有状态；
- 首次触发前为中性。

MACD 采用 EMA、ATR 采用 20 根有成交 15 分钟 bar，均为研报未完整披露处的预注册裁决。

### 6.2 初步趋势段和极值

每次初步趋势切换就结束一个趋势段。段边界只由初步 MACD 趋势决定，拐点修正不重新切段。每段同时维护最高价和最低价。

若当前初步趋势为上升：

```text
tempmax  = 当前上升段最高价
tempmin  = 当前上升段最低价
lastmax1 = 上一上升段最高价
lastmin1 = 上一下降段最低价
lastmin2 = 上两个下降段最低价
```

下降趋势完全对称，并额外需要上一、上两个上升段最高价。

### 6.3 拐点修正

- 初步上升趋势仅在 `tempmin > lastmin1` 时仍然有效；
- 初步下降趋势仅在 `tempmax < lastmax1` 时仍然有效；
- 条件失效时平仓并保持不可交易，直到新的初步趋势段产生；
- 修正不会把一段初步上升趋势直接变成可交易空头，反之亦然。

这是研报最终流程图三道同向闸的字面实现，也避免把“修正趋势”误写成高频反手条件。

### 6.4 道氏共振入场

多头入场必须同时满足：

```text
初步趋势 == up
tempmin > lastmin1
lastmin1 > lastmin2
Close_t >= tempmax_before_t
```

空头入场必须同时满足：

```text
初步趋势 == down
tempmax < lastmax1
lastmax1 < lastmax2
Close_t <= tempmin_before_t
```

最后一个条件先比较当前收盘价和本 bar 之前的临时极值，再把当前 bar 的高低价纳入极值。若先更新极值，`Close >= current High` 或 `Close <= current Low` 几乎只会在收盘恰等于最高/最低价时成立，与“突破”语义不符。

入场后锁存方向，持有到初步趋势切换或拐点条件失效。不要求每根 bar 重复突破临时极值。报告另跑“不锁存、逐 bar 重验全部三道闸”的字面敏感性变体，但不得据此挑选结果。

若同一根 bar 平掉原方向且满足反向完整入场条件，则在下一五分钟窗口直接反手，并计两次单边成本。

### 6.5 品种筛选

所有品种运行独立影子策略。月末对当前满足流动性条件的品种检查此前 252 个交易日：

- 完成交易少于 5 笔：剔除；
- 完成交易不少于 5 笔，但累计净收益小于 0：剔除；
- 其余保留。

影子收益包含 ATR 杠杆和 1.3 bp 单边成本，不包含组合级已实现波动率调整。

### 6.6 资金和杠杆

```text
Lev_ATR = clip(0.005 * real_close / ATR20, 0, 4)
Mul_vol = 0.15 / portfolio_realized_vol_252d
Lev     = clip(Lev_ATR * Mul_vol, 0, 4)
Target  = direction * active_position_weight * Lev
```

`Mul_vol` 月末更新、下月固定。资金只在当前实际持仓品种间等分；无信号品种不占分母。

### 6.7 样本

- 研报忠实样本：2012-01-04 至研报年度表明确标注的 2022-07-29；
- 样本外：2022-08-01 至可靠数据上界，当前为 2026-01-30；
- 研报对照：年化收益 21.74%、Sharpe 1.42、最大回撤 9.90%、Calmar 2.20、年化波动 15.34%。

## 7. 月度状态变化和换月

### 7.1 品种池变化

新月份首个交易时段开始时，实际账户向影子策略目标对齐：

- 退出池且有实际仓位：按首个可成交五分钟窗口平仓；
- 新入池且影子策略已有持仓：按同一窗口建立对应仓位；
- 留在池内：保留其策略状态，不因月界重置指标、止盈线或趋势段。

影子状态对未选中品种持续推进，避免新入池后丢失入场时冻结的 OI 倍率、止盈线或道氏趋势历史。

### 7.2 主力切换

主力合约变化时，在新交易日首个可成交窗口：

1. 用旧合约真实价格平掉旧仓；
2. 用新合约真实价格建立等风险新仓；
3. 两条腿分别计成本；
4. 指标和策略状态不重置。

缺任一腿可成交价格时严格失败。报告把策略方向交易与纯展期交易分开归因。

## 8. 成本、账户和收益

- 单边交易手续费 0.3%%、冲击成本 1%%，合计 1.3%%，即 1.3 bp；
- 每次目标名义仓位变化均按变化量计成本；
- 反手计两倍换手，换月两腿分别计费；
- 账户逐事件计价，不能用日收盘仓位乘日收益近似分钟成交；
- 日收益由该交易日全部事件归集；
- 组合已实现波动使用最近 252 个完整日收益的样本标准差并年化；
- 不满 252 个观测时不启用实际策略杠杆，CLI 必须明确预热不足，而非把乘数默认为 1。

## 9. 错误处理与数据质量

忠实模式下以下情况必须非零退出：

- 请求区间超出交易时段规则资产上界；
- 缺少必要交易时段、合约乘数、复权收盘价或主力数据；
- 应成交窗口无法定价；
- 关键 OHLC/OI 非有限、负成交量、重复分钟键或分钟不落合法槽位；
- 月度波动率应存在但为零、负数或非有限；
- 产物已有但其配置或输入摘要与本次运行不一致。

以下情况是可报告的已知降级，不应伪装成精确 VWAP：

- 郑商所合成成交额改用 OHLC typical price；
- 参照连续合约表缺席导致主力无法对账；
- 品种因历史不足、交易不足或负表现未入池；
- 无成交 bar、未上市区间和非交易时段。

## 10. 输出

每个策略分别生成：

### 10.1 Excel

- `metrics`：`full`、`in_sample`、`out_of_sample` 分行；

- `data_quality`：缺失、降级、拒单和覆盖统计；
- `fidelity`：研报原文、默认裁决、依据、敏感性变体和结果差异；

- `<prefix>.png`：净值、回撤、杠杆与样本内/外分隔线；
- `<prefix>.audit.json`：SQL 查询计划摘要、数据范围、规则资产摘要、异常计数、复刻指标差异和产物内容摘要。

## 11. 验证策略

### 11.1 单元测试

共享层至少钉住：

- 六个月窗口不读当月、成交额分母和郑商所孪生去重；
- 双最大、不成立沿用、不可逆和一日滞后；
- 后复权展期公式和真实/复权价格隔离；
- 15 分钟桶、无成交 bar、跨时段五分钟窗口和定价降级；
- 月度筛选只读上月末前的 252 个观测；
- 换月、反手、筛选进出池的事件账户与成本。

Bollinger 至少钉住：

- 300/1.5 通道、穿越而非通道外状态入场；
- OI 150/300 倍率和交易期内冻结；
- 中轨退出、固定八倍标准差止盈；
- 止盈后不原地重开；
- 筛选条件中 Sharpe 与 Calmar 的“同时小于零”。

道氏至少钉住：

### 11.2 因果与变异测试

- 修改未来行情不得改变过去宇宙、主力、信号、筛选或杠杆；
- 去掉一日主力滞后、月初截止或临时极值更新顺序时，专门测试必须失败；
- 交换真实价与后复权价时，展期和手数测试必须失败；
- 把穿越事件误写成持续状态时，止盈后重开测试必须失败。
