## 全历史验收：时段歧义清零（2026-08-31）

- 面板依赖的时段规则资产口径太窄。收窄两刀后（只留曾入池的 63 个品种；每个品种只从
  首次入池前 252 个交易日起，两刀都可证明行为中性），仍有 23,676 个品种日缺规则；
  采集驱动落在 `scripts/commodity/capture_sessions.py`，发布**第三份**资产
  `config/commodity_minute_sessions.csv`，Carry 与连续两份一字不动。
- **普查已干净**：170 个月、阻塞 0、边界观测缓存已落盘。唯一采不到分钟的 937 个品种日
  全是 FU 2012–2015，被「首次入池前 252 天」那一刀整段消掉。
- **547 条歧义拆开后只有三类，没有一类需要逐日裁决**：

  | 成因 | 条数 | 处理 |
  |---|---:|---|
  | 缓存把可空布尔列写成 float，竞价归位规则（问 `is True`）静默失效 | 52 | 按 dtype 还原布尔列；缓存带格式标记，认不出的旧缓存拒读 |
  | 观测只能从时段**内部**约束时段：薄品种首笔成交晚于开盘、末分钟不成交、整夜零成交 | 317 | 开盘改由同交易所当天最早的一笔成交给出；收盘容忍落在最后一个 15 分钟槽内 |
  | 资产转录缺口（MA/ZC/BU/FU 上夜盘前的窗口、INE 2018-04-09 节后无夜盘、上期所 2019-12-26 漏抄的 SN） | 178 | 六行照抄已登记的批次公告，无新裁决 |

- 「取同交易所当天最早的一笔成交」对薄流动性免疫（薄只会把自己的首笔推晚），又保留了
  发现交易所改开盘的能力：全历史 9,955 个交易所日里 9,951 个共识为 21:00，另外 4 个正是
  2019-12-26 全市场延迟到 22:30 的那一晚。
- 发布前的重放复核必须与主通道读同一件事（同一个交易所-日开盘、同一批 day-only 规则），
  否则会炸在 BU 上夜盘首夜 —— 那一夜 BU 只成交了一分钟，还落在零点之后。
- 面板构建器的时段资产改走 `--session-rules` 参数：同一个 `main` 服务连续信号与商品复刻
  两个消费者，两份资产不可互换（连续要 2011 年、商品从 2012-01-04 起）。

## 全历史 build 才现形的五个缺陷（2026-08-31，均已修 + 补测试）

时段歧义清零之后，真跑全历史 build 一次炸一个，每个都只有真实数据才有的形态：

1. **FU 2018 那处唯一的真断代被判成缺数据**。判据第 3 条原写「旧合约让出主力后就再没有
   收盘」——归档给已挂牌未成交的合约照打结算价（老 FU 合约零成交打到 2018-06-28），
   按那条判据反而把断代判成缺数据。改判「**主力链在这里断过**」。
2. **覆盖闸与构建侧在不同地方裁月份**。前态那一天（资产起点月借的是 2011-12-30）被索取
   时段规则，而闸按月裁掉了它。两边现在同一刀。
3. **96 次换月定不出价**（3,406 次里 2.8%，14 个品种、每年都有）：链断（AU1912 到期十天后
   主力才换到 AU2006）与薄成交（WR/B/SF/SM，以及当天有成交但不在开盘五分钟里的 PP1405）。
   **用户裁决：不发换月成交单**，连续价仍由日线复权因子缝合，清单一次报全
   （`roll-fill-unpriceable.csv`）。
4. **bundle 跨表校验要求「每个换月都有成交单」**——这条会在写 bundle 的那一刻杀掉整跑。
   改成：可以缺，但缺的条数必须与 manifest 申报一致。
5. **两条策略的影子也硬要求每次换合约都有成交单**。仓位不能"平移"过去（两张合约原始价
   不可比），因此与断代同样处理：切换前最后一根强制平仓、状态机清空、新合约重新开始。

保真度表：F8 记下 96 次的价差成本按 0 记与平仓口径，F10 改正断代判据的措辞。
