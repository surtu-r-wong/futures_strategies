# 前向账户实施计划

范围：落实 operational-returns/forward-account-implementation.md，只实现旁路软件和合成验收，不修改生产目标脚本、初始化真实账户或部署。原 response.md 保持不变。

1. `forward_account/`：显式参数校验、原生目标 CSV + 配置/来源收据适配；支持 Carry tsindex 纯版、λ=0.20 混合版和修订后 027。目标权重已经含原生杠杆，不再缩放或换主力。
2. 线性 CNY 期货 paper 账户：按日历指定的日盘执行时点、估值/结算时点，用前一状态的固定数量计 PnL，复用 `common.minute.account.EventAccount` 的价格变动核算；按执行时点扣交易名义费用，持久保存现金、数量、结算基准和审计。明确拒绝不支持的现金流、多币种、借款与期权。
3. 本地 SQLite 事务保存配置、完整日历、不可变输入/状态版本和账户 head；相同输入幂等，缺输入回滚，尾日修订须理由并保留前版，旧日修订不隐式重放历史。发布原子替换，发布失败可从已提交状态恢复。
4. CLI 提供初始化、增量入账、导出入口。真实账户使用实际初始化时间，只从其后的完整区间出收益；合成数据与正式入口隔离。导出涵盖初始化后的全部成功日，符合原 Schema。
5. 测试先定义独立算式：至少两个连续区间、原生杠杆、数量变动/手续费、重复运行、缺行情回滚、版本拒绝、结算现金与 NAV、尾日修订、发布恢复及 Schema。交付独立合成文件和可复现命令。
6. 同目录 implementation-response.md 登记 14 条支持状态、参数缺口、触发方案、实际 checkout 和发布指纹；不对真实收益截止承诺 SLA。

真实资本、初始化、费用、合约单位和保证金证据、完整日历及市场数据采集收据尚待集中落实。测试参数仅为合成算例，配置无生产默认资金/成本/保证金。
