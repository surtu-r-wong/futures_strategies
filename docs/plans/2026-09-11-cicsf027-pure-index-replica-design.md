## 1. 为什么要另起一条路径

生产引擎 `cta_carry` 产出的是**策略账本**：15% 波动目标、4 倍毛敞口上限、4 bps 成本、
T+1 开盘成交。中信发布的是**纯指数**：基日 2010-01-04 = 1000 点，无杠杆、无波动目标、
无成本、收盘价口径。两者不可能逐点对上，所以"复刻得像不像"这个问题在生产引擎上**问不出来**
——量到的是混合权重的变化，不是指数的相关。

2026-09-09 研究脚本 `others_test.py` 测得我方 027 与官方相关只有 0.39（025 同法是 0.99 量级），
但该脚本未入仓、已随 scratchpad 清除，其具体选择无法复核。本设计重新从编制方式出发。

## 2. 编制方式的规则（3.1–3.5 摘录）

**3.1 基差动量定义**

```
BM_it = ∏(s=t−R−1 .. t) (1 + r^T1_{i,s})  −  ∏(s=t−R−1 .. t) (1 + r^T2_{i,s})
```

- `r^T1` = 较早到期的主力合约 T1 的日收益率；`r^T2` = 较晚到期的次主力合约 T2 的日收益率
- R = 动量的计算周期（**文件未给数值**）
- 主力 = 持仓量最大的合约；次主力 = 主力之后持仓最大的合约

**3.2 品种选择**

- 流动性：过去 **20 个交易日**平均**沉淀资金 ≥ 20 亿**
- 上市时间 **≥ 三个月**
- 特殊调整：① 品种调整期内涨跌停的品种排除；退市或其他特殊情况排除
  ② 指数测试考虑历史流动性较高的 **37 个品种**（下方 §4 列全）

**3.4 换月**：主力与次主力都是持仓量最大者，**一旦切换只能切换到到期日更后面的合约**（forward-only）

**3.5 指数计算**（每个 T+1 走一遍）

1. 定义主力合约（**主力合约持仓之前的持仓最大的合约，如果没有就是主力**）和次主力合约
   （主力合约之后持仓最大的合约），计算合约池中合约的基差动量为 **`R_i` ÷ 远近主力合约的相隔月数**
2. 依据第一步的值**从小到大**排序，序号 `1:N`，得到 `Rank_i`
3. `w_i = (Rank_i − (1+N)/2) ÷ (N(1+N)/2)`
4. `R_{T+1} = Σ w_p·r_p`；换月日单品种收益率 `r_i = w̄·r_new + (1−w̄)·r_old`，
   `w̄` 为新合约的合约价值占比
5. `MoMI_{T+1} = MoMI_T × (1 + R_{T+1})`

⚠️ **3.1 与 3.5 第一步对 T1 的定义不一致**：3.1 说 T1 是"较早到期的主力合约"、主力是持仓最大者；
3.5 第一步说主力合约是"主力合约持仓之前的持仓最大的合约，如果没有就是主力"。
**以 3.5 为准**——它是指数计算的操作步骤，且与 025 编制方式里的近月腿定义一致。

### ⑧ 是对照 025 文本才看出来的（2026-09-11 实现期间新增）

027 的 3.1 写：「本策略也具有如横截面动量策略一样的**回望周期**这一个参数。回望周期即将
回望周期内的基差动量值作为当前的单品种的基差动量因子值。」——句子本身读不出要不要平均。

但 **025 编制方式的同一句写全了**：「回望周期即将回望周期内的期限结构值**算术平均值**作为
当前的单品种的期限结构因子值」，且其 3.5 第二步再次点明「求出 **p 日(参数)** 展期收益率
R_i 的**平均值 meanR_i**，依据 meanR_i 进行从小到大排序」。

两份文件的 3.2–3.5 逐字相同，只有 3.1 的因子定义不同 ⇒ 027 那句是同一句式**省掉了
"算术平均值"四字**。据此判定：**027 的因子 = 回望期内 BM 值的算术平均**，于是它有两个
参数——BM 公式内部的 R，和其外的回望期 p。本设计先按 p=1（即当日 BM）实现，
把 p 作为参数留在 Task 10 一并标定。

### 另：025 的 3.1 与 3.5 也互相矛盾，取法同 027

3.1 写 `TS = (P近/P远 − 1)^[12/(远月−近月)]`（指数形式、年化），3.5 第一步写
`R_i = (近收 − 远收) ÷ 近收 ÷ 相隔月数`（除法、无年化）。**以 3.5 为准**——年化是全截面
同一个常数，动不了任何排名。生产 `cta_carry` 的 `carry_raw` 带 `×12`，同理不影响排序。

**口径差（非偏差）**：中信是纯指数，我们是带波动目标/杠杆上限/成本的策略账本。

**自由参数**：R 未给数值。生产腿用 500 交易日。本路径按 §6 标定。

## 5. 验收判据

官方序列在库里：`stock_selector.index_daily` 的 **`CICSF027.WI`**，4054 行、2010-01-04..2026-09-10，
基日与基点均与编制方式吻合。

| 判据 | 目标 |
|---|---|
| **日收益相关** | 主判据。025 同法可达 0.99 量级，027 现状 0.39 |
| **年化波动比值** | 新增。首轮复刻波动只有官方 38%（2.34% 对 6.16%），而秩权重的毛敞口
恒约 0.48 且与 N 无关 ⇒ 若控制臂也整体偏小，是权重归一化读法的共因，不是 027 的问题 |
| 净值水平相关 | 辅助 |
| 年化 / 夏普 / 回撤 | 对官方 11.0% / 1.79 / −11.9% |
| 逐年收益 | 找出分歧集中在哪些年份 |

**必须先跑控制臂**：同一个新引擎按 025 编制方式跑一遍期限结构指数，与 `CICSF025.WI` 比。
025 已知可复刻（9.37%/1.90 对 9.31%/1.89），**若新引擎连 025 都复刻不出来，那么 027 的任何数字
都不能归因给 027**。这是安慰剂臂的同一招（见记忆 `sharpe-comparison-is-low-power`）。

## 6. R 的标定

编制方式未给 R。做法：在 {60, 120, 250, 500, 750} 上扫，**按与官方序列的相关挑**，不按收益挑。
这在复刻语境下是正当的——目标是拟合那条**已公布的序列**，不是拟合收益。挑完必须报全表，
不能只报选中点（见记忆 `report-sensitive-quantities-at-the-selected-point`）。

## 7. 待裁决

1. **ZC 动力煤怎么处理**：2022 年后成交枯竭。按 3.2「其他特殊情况」排除？还是让流动性闸自然
   把它筛掉？两者对 N 的影响不同。
2. **「品种调整期内涨跌停排除」的口径**：是当日涨跌停就排除，还是调整日涨跌停才排除？
   编制方式只写了前半句。
3. **换月日 `w̄`「新合约的合约价值占比」的读法**（实现时新增）：3.5 第四步只说 `w̄` 是
   新合约的合约价值占比，没说分母是什么、取哪一天的价。本实现取**同品种两腿在换月日
   开始时（昨收）的合约价值之比** —— `close_new(t−1) ÷ (close_new(t−1) + close_old(t−1))`，
   两腿同品种故乘数相消。理由：把两个持仓的收益合成一个组合收益，权重就该是期初价值。
   若相关上不去，另两种读法待试：用当日收盘算占比；或 `w̄` 指已迁移到新合约的持仓比例
   （那需要一个换月进度表，编制方式没给）。

4. **3.1 那句「回望周期即将回望周期内的基差动量值作为当前的基差动量因子值」**：最自然的读法是
   回望周期 = R（3.1 公式里的 R 已经是窗口长度），但也可读成在 R 之外再套一层平滑。
   本设计按前者实现，若相关上不去再试后者。

## 8. 不做什么

- 不动生产出单路径。`cta_carry` 那条腿保持现状（λ=0.20），本路径是独立的研究复刻。
- 复刻结论出来之前，**不据此改生产腿的 λ 或口径**。
