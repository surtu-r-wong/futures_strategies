## 1. 每天怎么跑

```bash
cd /home/elfbob/claude-code/futures_strategies
scripts/citic027_daily.sh <资金规模CNY> [as_of=今天]
.venv/bin/python scripts/check_citic027_sheet.py output/targets/citic027_<END>
```

**时点与 carry 相同**：交易日 T 的日线凌晨 03:00–03:10 才齐，所以 **T+1 早上（08:00–08:30）跑，
出当天 09:00 日盘开盘要执行的目标持仓**。

**截断日每次现算**：脚本先跑 `python -m cta_carry.coverage`，取五家商品交易所
（CZC / DCE / GFE / INE / SHF，不含中金所）各自 `max(trade_date)` 的**最小值**作 `--end`。
大商所靠人工投递、多数早晨落后一天；照全表最大日跑会把大商所品种全读成没有 K 线。
滞后的交易所会打到 stderr 与 `output/targets/citic027_daily.log`。

产物：`citic027_<END>_next_targets.csv`（下单用 `order_code` 与 `lots` 两列）
与 `citic027_<END>_config.json`（完整配置 + 诊断）。

## 2. 这条策略是什么

中信 CICSF027 基差动量策略指数的**可成交复刻**，不是那条指数本身。

| | |
|---|---|
| 因子 | `BM = ∏(1+r^T1) − ∏(1+r^T2)`，R=150 交易日，**不除相隔月数** |
| 腿 | **持仓量前两名合约按到期先后排序**（3.1 的读法），T1 近 T2 远 |
| 排序/权重 | 全截面日频重排，`w=(Rank−(1+N)/2)÷(N(1+N)/2)`，和恒为零 |
| 品种池 | 20 日均沉淀资金 ≥20 亿 + 上市满 3 个月 + 调整日非涨跌停；**开放宇宙**（全商品，排除中金所） |
| 交易标的 | 主力合约（3.4：指数用主力合约的数据） |
| 收益口径 | **收盘对收盘**（可成交），不是中信那条"除以前结算价" |
| 尺度 | 15% 年化波动目标（252 日滚动），毛敞口上限 4 倍 |
| 执行 | T+1 日盘开盘 |

⚠️ **参数取值的依据**（`-results.md` §5）：R=150 同时落在夏普峰值与相关峰值附近
（相关 0.553 对最高的 0.556，夏普 2.486 对次优 2.411），两个判据不冲突。

## 3. 每次跑完必做的验收

```bash
.venv/bin/python scripts/check_citic027_sheet.py output/targets/citic027_<END>
```

它查七件事，其中**第二件是这个脚本存在的理由**：

1. 波动窗是否够 252 天
2. ⭐ **波动窗内每一天是否都有真实截面**（`vol_window_min_products ≥ min_products`）
3. 毛敞口 ≤ 4 倍
4. 净敞口 = 0
5. 品种不重复、手数不缺
6. **手数与 `notional ÷ (收盘 × 乘数)` 重算一致**（这是唯一会被抄进下单票的数）
7. 单子日期与运行记录一致

### 为什么第 2 条是核心

`vol_scale = 0.15 ÷ 最近 252 个指数收益日的年化波动`。若那 252 天里有些天几乎没持仓，
波动会被读低、账本被多加杠杆，**而最后一天看着完全正常**。

carry 的日跑 2026-09-11 就是这么错的：60 天窗口让波动读成 4.13%（收敛值 4.77%），
**多加 15.6% 杠杆、49 行错 47 行、最大一行差 42 手，全程不报错**。
本脚本的窗口因此取 **900 天**（≈615 个交易日，而最低需求是 252+150≈402），
且 `daily.py` 在波动窗未满时**直接 abort，不出单**。

## 4. 已知边界与风险

- **回测是 2026-09-11 当天跑出来的，全样本内、无样本外。** R=150 的夏普是在同一段数据上挑的。
- **逐年极不稳**：2023 夏普 0.30、2024 夏普 3.71。任取两三年都会得出误导性印象。
- **需要约 5.8 倍杠杆**才到 15% 波动（毛敞口 ≈2.9 倍净值），因为秩权重的原始毛敞口只有 ≈0.49。
- **全期回撤 −23%**（可成交口径、15% 波动、4bps）。
- **年换手 12.1 倍**，4bps 下成本约 0.48%/年 @1×，加杠杆后约 3%/年。
- **与 carry 并行则总敞口叠加** —— 资金规模是命令行参数，这条代码管不了。
- ⚠️ **2025-02 起官方 027 序列自身发生了我方无法解释的变化**（年化波动 11.86%，
  是它 16 年最高，而同族另三条没动）。我方复刻不再跟踪它，但这意味着
  **"与官方对得上"这个验收判据在后段已失效**。
