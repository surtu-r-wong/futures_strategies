## 0. 一句话

跑之前先读 §3「取数边界」和 §5「保真度声明」。这两节里的日期是**实测出来的**，
会随上游补数而移动；移动时连同研究档一起改。

## 1. 跑法

```bash
cd ~/claude-code/futures_strategies
.venv/bin/python -m index_open_momentum \
    --start 2016-01-04 --end 2020-12-31 \
    --products IF,IC,IH \
```

产出三件：

| 文件 | 内容 |
|---|---|
| `<prefix>.xlsx` | 七张表：`metrics` / `daily_returns` / `annual_returns` / `trades` / `signals` / `leverage` / `data_quality` |
| `<prefix>.png` | 净值图，图上标出 2021-05-13 那一刀 |
| `<prefix>.audit.json` | **`EXPLAIN` 产物存档** + 乘数出处 + 分段指标 |

⚠️ **`EXPLAIN` 存档位置 = `<prefix>.audit.json` 的 `plans` 字段。** 留在内存里的
计划摘要在验收时等于不存在，所以每次运行都落盘。共享层的闸是"引用超过 3 个
Timescale chunk 即报错"、"预计行数 ≥ 1000 万即报错"；实测真候选各只引用 **2 个 chunk**。

## 2. CLI 当场拒绝的四种组合

| 拒绝 | 原因 |
|---|---|
| `--end` 越过 **2026-08-11** | `futures_minute` 最新 bar；再往后是在要不存在的数据 |
| 区间跨越 **2026-04-29** | 主力合约在边界两侧来自不同的表（见 §3）。跨界要分两段跑并在报告里显式说明拼接口 —— 静默拼接会让换月规则在中间悄悄变一次 |
| 区间落在 2016 前却带 `--require-paper-faithful` | 那段缺 15:00–15:15，结构上标不了（见 §5） |
| `--products` 含 IM 却要 paper-faithful | IM 2022-07-22 才上市，不在研报样本里 |

## 3. 取数边界（2026-08-27 **逐月**实测）

⚠️ **`max(trade_date)` 会骗人**：`futures_daily` 里 IF 的最大交易日是 2026-08-26，
但那是孤零零一天 4 行；2026-05/06/07 一行都没有。判可用上界必须**逐月数行**。

| 表 | 可用区间 | 角色 |
|---|---|---|
| `public.futures_minute` | 2010-04-16 ~ **2026-08-11** | 分钟数据；尾部的持仓量与成交量 |
| `public.futures_daily` | ~ **2026-04-29** 连续 | 主力合约来源 |
| `public.futures_contract_info` | **2025-12-22** 起连续 | 尾部合约名单（混着 Wind 合成码，须滤四位交割码）+ 合约乘数 |
| `public.continuous_contract_ohlc` | ~ 2026-04-29 | **只**当对账参照，不当数据源 |
| `public.trading_calendar` | 2000-01-01 ~ 2026-12-31 | 交易日历。**没有 CFFEX 列**，用 `sfe`（2010–2025 逐年与 IF/IC/IH/IM 日线行数一个不差） |

**实盘前需补尾**：`futures_minute` 停在 2026-08-11，要出实盘信号必须先把这条尾巴补上。

## 5. 保真度声明（复刻假设逐条，全部要进报告）

### 5.1 数据侧

1. **2016 前缺 15:00–15:15**（本库每个交易日最后一根 bar 是 14:59，而中金所当时
   交易至 15:15）。不影响开盘信号，**影响 2011~2015 的日内收盘平仓价口径**。
   已登记为授权缺席 `cffex_pre2016_close_tail`，逐日写进 `data_quality` 表。
   ⇒ **2016 前的区间不得标 paper-faithful。**
2. **成交价越界容差 1e-6**（共享层给商品涨停 bar 的是 1e-4）。实测 2,139 个真实
   执行窗口最大越界 **0.0**。零宽窗口豁免闸门但度量照报。
3. **合约乘数**优先取 `futures_contract_info`，缺失才反推。样本跨不足 3 个交易日时
   用元数据兜底，`source` 记 `metadata_unvalidated`，样本一够自动升级为校验过。
   ⇒ 报告里凡是 `metadata_unvalidated` 的合约都要点名。

### 5.2 策略侧（研报沉默处的显式裁定）

① ATR 取 16 根简单均值非 Wilder；② TR **跨隔夜计入跳空**（ATR 在跨日连续序列上算，
因为 16 根窗口 ≈ 股指一个交易日）；③ 入场后极值从建仓那根之后起算；
④ ATR=0 取"当日不建仓"而非把 +inf 截到 4；⑤ 不满一年波动率历史取"不建仓"；
⑥ 等权分母是**当日活跃**品种数非恒定 3；⑦ 波动率窗口取最近 252 个**观测**
而非 365 个**自然日**；⑧ 已实现波动率用**样本**标准差 `ddof=1`；
⑨ **无成交 bar 打断反向信号的连续计数**（非透明跳过），空头收盘平仓必须用
**入场之后**有成交的 bar；⑩ **主力合约滞后一个交易日**选取（持仓量当日收盘才知道，
拿它选当日合约是回看）。

⚠️ 已实现波动率为 **0** 时同样不建仓 —— 某品种一整月没有信号时它那段日收益全是 0，
标准差就是 0，杠杆无定义。

## 6. 与论文对账

研报头条：样本自 2011-06 起，**费后年化 25.79% / Sharpe 1.77 / 最大回撤 7.66% /
Calmar 3.37**。差异**逐项归因，不调参逼近论文收益**。

## 7. ⛔ 样本外必须单独成段

研报日期 **2021-05-13**、样本自 2011-06 起 ⇒ **其样本止于 2021**。
报告的 `metrics` 表逐段一行，`full` / `in_sample` / `out_of_sample` 三段并列；
净值图上把 2021-05-13 画成竖线。**不允许只给全样本合并数。**

理由不是谨慎，是本仓已经撞过一次：国信 Carry 那篇的样本**恰好止于策略失效之前**
（七个不重叠窗口里四个为负，2021 后连续三个为负且逐段恶化）。同一家、同一类研报，
先验上应当假设这里也一样 —— 别等全做完才发现又是同一个形状。
