# 两份时段资产的交叉验证（2026-08-28）

## 为什么做

设计 D3 选了「按连续宇宙**整体**重采」而不是只补那 1,713 个缺口。多出来的代价换到的东西，
就是重叠部分构成一次**对现有 Carry 资产的独立验证** —— 两次采集的宇宙不同、池子口径不同、
相隔数月，若在共同覆盖的品种日上逐点相同，那是对两份资产的有力背书。

## 做法

把两份资产各自展开成 `(exchange, product, calendar_date) -> 时段分段`，取交集逐点比对。
展开时对同一键出现两次即断言失败（两份资产各自内部不得有重叠规则）。

## 结果

| | 品种日 |
|---|---:|
| `carry_minute_sessions.csv` 覆盖 | 176,190 |
| `continuous_minute_sessions.csv` 覆盖 | 177,730 |
| **重叠** | **175,134**（占 Carry 99.4%，占连续 98.5%） |
| 重叠部分**一致** | **175,134** |
| 重叠部分**分歧** | **0**（一致率 100.000000%） |
| 仅连续有 | 2,596 |
| 仅 Carry 有 | 1,056 |

**零分歧。** 无需裁决。

两侧的非重叠部分与预期形态吻合：

- **仅连续有的 2,596 个**：本次补采的左边缘（22 个品种各一段 3-5 个月，进入 ≥50 亿宇宙早于
  进入 Carry 池）、右边缘与内部空洞，加上采集本身「池内品种日 + 2 个后继交易日」的外扩。
- **仅 Carry 有的 1,056 个**：Carry 池覆盖而连续策略不交易的品种日。典型如换月拉锯期的黄金 ——
  研报要求「双最大」，无合约同时持仓量与成交量最大时该品种当天没有主力（AU 全历史 3,664 天中
  有 38 天如此，集中在每年 12 月下旬）。

## 结论

两条独立路径对同一物理事实（交易所时段）给出完全一致的答案。这既验证了本次补采，
也回过头验证了 Carry 那份资产 —— 后者此前从未被独立复算过。
