# 连续信号四道闸的几何（2026-08-31）

写在全历史回测之前。下面全部是**指标定义本身**的性质，在合成路径上量出来的，
不是对真实回测结果的断言 —— 那还没跑。记在这里是因为它决定了结果该怎么读。

## 一、`ΔTNR > 0` 在任何光滑趋势上恒假

`TNR_{t,N} = |C_t − C_{t−N}| / Σ|C_i − C_{i−1}|` —— 位移比路程。路径单调时位移
**恰好等于**路程，所以 `TNR ≡ 1`。而

```
ΔTNR_{t,k} = TNR_t − mean(TNR_t, …, TNR_{t−k+1})
```

在 `TNR` 连续三根都是 1 时**恰好等于 0**，不是接近 0。研报的开仓条件要求
`ΔTNR > 0`（D3），于是这道闸在光滑趋势上**严格关闭**。

研报基线参数（EMA 12/26、N=20、k=3）、400 根合成 bar、预热后 374 根：

| 路径 | 距离扩大 | ΔTNR>0 | 两者同时 | TNR 尾段均值 |
|---|---:|---:|---:|---:|
| 线性趋势（等步长） | 99.2% | **0.0%** | 0.0% | 1.0000 |
| 加速趋势（二次） | 100.0% | **0.0%** | 0.0% | 1.0000 |
| 几何趋势（恒定收益率） | 100.0% | **0.0%** | 0.0% | 1.0000 |
| 随机游走 | 45.2% | 49.2% | 30.7% | 0.2489 |
| 带漂移随机游走 | 48.4% | 48.4% | 31.3% | 0.2773 |

三种趋势形状（线性 / 二次 / 几何）给出同一个 0.0%，所以这不是某条路径的巧合，
是 TNR 上界为 1 的直接后果。

**这不是缺陷，是研报的设计**：`ΔTNR` 度量的是「噪音正在减少」，不是「趋势正在
进行」。趋势已经干净到 TNR=1 时，它没有进一步变干净的余地，闸自然关上。

## 二、「距离扩大」几乎是免费的 —— 与我先前的判断相反

我原以为稳定趋势里两条 EMA 的间距会收敛、从而让「距离扩大」失效。**实测推翻了这条**：
线性趋势下间距单调收敛到 14.0，但每一步都还在**增大**，所以 `|短−长|_t > |短−長|_{t−1}`
一路为真（99.2%）；加速与几何趋势更是 100%。

真正在筛选的是噪音闸，不是距离闸。随机游走上距离闸才回到约 45%~48%。

## 三、对结果解读的三条

1. **信号天然是断续的。** 闸门在趋势变干净的过程中打开、在趋势干净之后关上。
   配合 D6（任一闸不过即空仓），持仓会反复进出 —— 这是口径决定的，不是参数没调好。

2. **计划 §6 风险 ① 是结构性的，不是偶发的。** 等权组合里品种反复进出，权重要全盘
   重算。Carry 那条线的真凶正是过滤器抖动（53% 换手 / 年化 4.16% 成本，
   见 `carry-cost-is-filter-whipsaw`），而这里 60+ 个品种只会更凶。所以换手四分解
   与逐类成本贡献是**判读结果的前提**，不是锦上添花。

3. **别拿「趋势里信号一直开着」去校验实现。** 一条让信号持续开着的价格路径在这个
   口径下不存在。单测的夹具因此必须构造 **TNR 严格上升**的锯齿（上行腿恒增、
   回撤腿恒减），见 `tests/test_continuous_backtest.py::_zigzag`。

## 复算

```bash
.venv/bin/python - <<'PY'
import numpy as np
from cta_continuous.indicators import ema, gap_widening, tnr_series, delta_tnr
n = 400
for name, closes in (
    ("线性", [1000 + 2.0 * i for i in range(n)]),
    ("二次", [1000 + 0.02 * i * i for i in range(n)]),
    ("几何", [1000 * (1.001 ** i) for i in range(n)]),
):
    c = np.asarray(closes, float)
    s, l = ema(c, span=12), ema(c, span=26)
    d = delta_tnr(tnr_series(c, window=20), k=3)
    warm = 26
    print(name, "ΔTNR>0 通过率", np.nanmean(np.asarray(d[warm:]) > 0),
          "距离扩大", np.mean(gap_widening(s, l)[warm:]))
PY
```
