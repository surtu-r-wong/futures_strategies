# 国信道氏：铁矿石逐层对研报表 1/2/3

日期：2026-09-03
分支 `feature/guosen-bollinger-dow`，接 `docs/research/2026-09-02-guosen-replication-gap-diagnosis.md` §4 的「下一步」
对象：研报 §3 用铁矿石（I.DCE）单品种给出的三张分年度绩效表 —— 表 1 初步趋势判断、表 2 拐点修正、表 3 趋势共振。
这是研报里唯一**不经过选池、分母、波动乘数**就能对上的地方，所以能把差距按层切开。
原则不变：登记结果一个数没动；本文所有读法都是诊断旁路，不进登记产物。

## 0. 结论

1. **前两层复刻成立，第三层是缺口所在。** 按研报自己的口径（夏普 = 收益 ÷ 年化波动、Calmar = 收益 ÷ 最大回撤、
   月胜率），ATR 杠杆下：L1 夏普 **0.58 vs 研报 0.69**，L2 **1.16 vs 1.08**（Calmar 0.95 vs 0.88、月胜率 62% vs 61%）；
   到 L3 我们 **0.71 vs 研报 1.26**。研报从 L2 到 L3 夏普**升** 0.18，我们**降** 0.45。差距不在 MACD 趋势、
   不在拐点修正，在「道氏趋势共振」这一层怎么读。
2. **研报的三张表是按附录二的 ATR 杠杆（0.5%·Close/ATR，截 4 倍）算的，不是 1 倍名义。** 证据是逐年波动的比值：
   ATR 杠杆下我们的 L1 波动 / 研报表 1 波动逐年 0.76–1.08（均值 0.93）、L3 登记读法 / 表 3 逐年 1.00–1.28（均值 1.13），
   九年里没有一年跑偏；1 倍名义下比值 0.7–2.0 乱跳。所以对表要用 ATR 杠杆那一栏。
3. **读法 C（日 ATR）在单品种层面被证伪。** 日 ATR 下铁矿石三层全灭：L1 夏普 −0.10、L2 0.04、L3 −0.09，
   影子账本波动只有 3.2%。研报表 1 的 0.69 只有 bar ATR 能给出。这与 09-02 文档 §3.3 用 Bollinger 图 5 做的反证一致，
   现在有了第二条独立证据。**C 不该升为登记读法。**
4. **研报的拐点修正是「反手」不是「只平」，但两种读法在铁矿石上的夏普几乎一样**（1.05 vs 1.16）。研报原文
   「则趋势发生反转，即判断为下降趋势」字面是反手；表 2 与表 1 的逐年波动之比每年都恰好 0.46–0.51，
   只有「始终在场」的读法能给出这么稳的比值（只平读法的在场率 78%，比值会随年份漂）。但研报表 2 的波动
   只有我们反手读法的 **1/1.93**，是一个常数缩放（逐年 1.71–2.30），来源不明（同一套杠杆下多出一个 ½）。
   夏普、Calmar、月胜率三个尺度无关量都对得上，所以 D4 改不改读法对这层无关紧要 —— **D4 不是缺口**。
5. **（09-03 重读原版 PDF 后补）第五种读法收口了：入场参照改成「第一高点」。** 研报 §3.3 的公式块在上升趋势下定义了
   lastmax₁（上一上升段最高价），正文三条开仓条件却一次没用到它；图 13 标注的也是「第一高点」与「临时高点」两个高点，
   而不是正文条件里的两个低点。把登记读法的入场从「收盘 ≥ 本段此前临时高点」换成「收盘 ≥ 第一高点」（其余不动：
   拐点有效、第一低点 > 第二低点、锁存到趋势切换或拐点失效），ATR 杠杆下铁矿石全样本
   **18.6% / 回撤 13.7% / 夏普 1.34 / 波动 13.9% / Calmar 1.36 / 月胜率 56%**，研报表 3 是 17.9 / 12.8 / 1.26 / 14.2 / 1.39 / 62 ——
   六列里五列在噪声内；逐年波动比值 0.80–1.12，逐年收益相关 0.65。它与登记读法在 88% 的 bar 上仓位相同，在场比例
   22% vs 28%、入场 59 vs 70 次/年 —— 差的正是那 9% 「本段新高但还没越过上一段高点」的 bar。§2.1/§3.4 有整表。
   **这是口径裁决，不由本文定**：正文写的是「临时高点」，公式块与图 13 指向「第一高点」，实证站在后者。
   **但它不是组合层缺口的解释**（§6/§7）：全历史组合样本内 2.66% → 5.79%、夏普 0.17 → 0.36，毛口径 15.3% → 18.3%；
   53 个品种逐一对比，32 好 21 差，平均夏普差 +0.035（t = 0.75）—— 它对上了研报举例的那一个品种，没有搬动横截面。
6. **其余四种 L3 读法没有一种能收口。** 登记读法 0.71、共振成立即持仓 0.86、仅道氏相反时空仓 0.55、反手读法上的
   突破锁存 0.51。共振即持仓的年化收益（17.9%）与研报（17.9%）一样，但波动 21% 比研报高一半、回撤 34% 是研报的 2.7 倍，
   不是同一条曲线。登记读法的在场比例与研报最接近（波动比值 1.13），逐年收益相关 0.65，但**每年均匀低约 6.5 pp**
   —— 与 09-02 文档在组合层看到的「均匀的水平差」是同一形态，现在定位到了单品种的共振层。
7. **执行不是缺口。** L3 登记读法按收盘价对收盘价算（0.71）与影子账本按真实 5 分钟成交算（0.70）几乎相同；
   1.3‱ 成本在单品种上可忽略。
8. **一条限制：L1 的逐年收益与研报只有 0.19 的相关**（2016 我们 −20% 研报 +26%；2019 +25% vs −12%；2020 +15% vs +77%），
   尽管夏普、波动、段节拍（每年 181 段、中位 27 根 bar，与研报图 13 的段长一致）都对得上。初步趋势的**切段时点**
   已经和研报不同，下游三层都继承这个差异，所以逐年表不能用来裁决 L3 的读法；能裁决的是尺度无关量的**层间变化方向**。

## 1. 方法

- 数据：`output/commodity-panel-v1` 的铁矿石切片（68,333 根 15 分钟 bar，2013-10-21..2026-01-30，单一连续段，
  36 次换月），影子层 `run_shadow_product` 登记默认（latched、bar ATR、20 根、1.3‱）跑一遍，
  三层的仓位全部从 signals 表已有的列重建（`cta_dow/layers.py`）：
  - **L1 初步趋势**：`trend` 的方向，中性为 0。
  - **L2 拐点修正**：只平读法 = `turning_valid` 不成立就 0（登记 D4）；反手读法 = 不成立就取反向（无前段极值可比时照旧）。
  - **L3 趋势共振**：登记读法 = `state_position`（共振 + 收盘突破临时极值入场、锁存到趋势切换或拐点失效）；
    共振即持仓 = 反手读法上「第一低点 > 第二低点」（空头对称）成立就持仓、不要求突破；
    仅道氏相反时空仓 = 只在道氏趋势明确相反时空仓，未定时沿用 L2；反手读法上的突破锁存 = 登记逻辑换成反手底座。
  - 影子账本 = `run_shadow_product` 自己的 `daily.net_return`（ATR 杠杆、真实成交、含换月）。
- 计价：复权价收盘对收盘，bar 内按上一根末的仓位计收益，换手按 1.3‱ 计成本，日内复利；不覆盖的 bar 不计收益、仓位顺延。
- 尺度：`unit`（1 倍名义）与 `atr`（0.005·Close/ATR，截 4，建仓那根定量、持有到换向，与影子账本同构）各出一份。
- 口径：逐年收益 = 当年复利简单收益（2022 为 7 个月，不年化，与研报同）；夏普 = 收益 ÷ 年化波动（ddof=1，√252，无无风险利率）；
  Calmar = 收益 ÷ 当年最大回撤；全样本收益按 CAGR。这套口径是从研报表里反推核实的：表 1 全样本 20.59/29.84 = 0.69、
  20.59/32.39 = 0.64；表 3 2014 年 13.67/10.88 = 1.26、13.67/6.66 = 2.05，逐格都对。
- 窗口：2014-01-01..2022-07-29（研报图 5/10/14 横轴自 2013-12-31 起，表到 2022-07-29）；预热用 2013-10-21 起的 bar。

| 上述段里随后出现收盘突破的 | 75.7% |
| `action` 计数（全 68,333 根） | no_resonance 27,780 / latched_hold 17,721 / turning_invalid 13,393 / no_breakout 6,222 / trend_changed 2,242 / dow_entry 837 |

共振是最重的闸（41% 的 bar），突破只挡 9%。研报表 3 的波动与我们登记读法的在场比例吻合，
说明研报的共振层在场时间与我们相近 —— 差的是**在场时的收益**，不是在场时长。

## 5. 对 09-02 三件待拍板的影响

   **新增一件要拍板的事**：是否把 D5 的入场参照从「本段临时高点」改为「第一高点」（上一同向段极值）。
   研报正文写「临时高点」，公式块与图 13 指向「第一高点」；实证站在后者。按计划硬规这是读法之争，改要写进保真度台账。
   组合层的数已跑（§6）：样本内 5.79% / 0.36，毛 18.3% / 1.16；与选池等分合并 4.16% / 0.36。横截面不动（§7）。

## 6. 「第一高点」读法在组合层是什么数（敏感性，登记不动）

状态机开关 `--breakout-reference prior_extreme`（`a082bd1`），全历史面板 2012-01-04..2026-01-30，其余登记默认；
再与 09-02 的选池等分（`--allocation selected`）合并跑一次。样本内 = 至 2022-07-29。

| 读法 | 样本内净 | 夏普 | 回撤 | 样本外净 / 夏普 | 样本内毛 | 毛夏普 | 成本/年 | 日换手 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 登记（`guosen_dow`） | 2.66% | 0.17 | 32.4% | −10.1% / −0.70 | 15.3% | 0.99 | 11.7% | 3.68 |
| 第一高点（`guosen_dow_prior`） | **5.79%** | **0.36** | 28.8% | −0.1% / −0.01 | **18.3%** | **1.16** | 11.3% | 3.57 |

见 §7。

## 7. 这条读法在整个宇宙上成立吗：逐品种影子账本对比

面板里 53 个在 2014-01..2022-07 有满一年数据的品种，各自跑两种读法的影子账本（ATR 杠杆、真实成交、1.3‱），
按研报口径算夏普（`output/diag_breakout_reference_by_product.csv`）：

| | 登记（本段临时极值） | 第一高点 |
|---|---:|---:|
| 品种数（更好 / 更差） | — | **32 / 21** |
| 夏普均值 / 中位 | −0.02 / −0.14 | 0.01 / −0.10 |
| 夏普为正的品种数 | 20 | 26 |
| 逐品种夏普之差：均值 ± 标准差 | | **+0.035 ± 0.34，t = 0.75** |
| 逻辑成交数 | 36,281 | 31,742 |
| 差最大的品种 | | BC +0.63、PB +0.63、**I +0.60**、SR +0.58、SM +0.42；PF −1.21、SC −0.82 |

铁矿石是第二大受益者。研报拿它举例，而它在我们的面板里本来就是登记读法下最好的品种之一（夏普 0.69，53 个里第 5），
换读法后 1.28 是全宇宙第二。**横截面上两种读法没有区别**：平均夏普都在 0 附近，只是名次重排。
这解释了 §6：一条只搬动少数品种、不搬动横截面的读法，进了选池与等分之后只剩 +3 pp 毛收益。

由此得到本文最硬的一条结论：**研报表 3 能被对上，说明信号的机械部分（趋势、修正、共振、突破）我们已经写对到
「在研报举例的品种上逐年吻合」的程度；组合层的缺口不在这些机械部分**。53 个品种影子夏普均值 ≈ 0 与研报选池
隐含的毛夏普 ≈ 1.7 之间的差，只剩三处可以放：① 初步趋势的切段时点（§0.8：L1 逐年相关只有 0.19，
MACD/ATR 的具体算法——均线种类、ATR 窗口——研报没披露）；② 数据：主力合约链、复权、时段拼接；③ 选池与分母。
这三处都不是「读法」，是登记默认与数据，每一处的验证都需要用户拍板范围。
