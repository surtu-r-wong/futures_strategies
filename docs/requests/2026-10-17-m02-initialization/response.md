## 2. D 日运行方案（2026-10-20 收盘后，手动按需）

**数据时点依赖**（均为既有生产链路，本仓只读）：

1. ~17:00 数据机 `run_daily.cmd`（既有手动日常作业）→ `public.futures_minute` 落 48 只非 CZCE 合约 D 日分钟 bar；该次 WindPy 会话同时刷新机器级 Wind API 登录态（见披露 4-5）；
2. EOD → `public.futures_daily` 落 D 日结算价（67/67）；
3. ≥21:00 本仓执行（两条命令，均幂等、fail-closed）：

```bash
# ① CZCE 19 只 09:30 bar 采集（持牌机一次性 WindPy 进程，带哈希收据）
.venv/bin/python scripts/m02_czce_wind_capture.py --trade-date 2026-10-20
# ② 建仓 + 首日推进（含结算）+ 导出收益
.venv/bin/python scripts/m02_futures_advance.py \
    --czce-receipt docs/requests/2026-10-17-m02-initialization/build/czce-2026-10-20.json
```

产出 `output/multi_asset/returns/latest.json`（ReturnFeed v1、synthetic=false、原子写）。

**重试语义**：advance 按 packet 哈希幂等（重跑同日不重复入账）；任一输入缺失即整单失败并报明确清单（不静默代用），数据到齐后重跑即可。**降级**：Wind 采集不可用时**报告并持账不动**——不顺延建仓日、不以夜盘开盘价代用（如需改变须另行裁决）。

**此后逐交易日**：只需命令 ②（数量冻结语义下无执行报价需求，仅结算盯市）。

1. **滑点口径差**：函件写"施加于原始价、按最小变动价位取整"；现行 contract-fees-v2 为**费用制**（4bp 记 CNY 成本，价格不加噪）。两口径对净值的差 <0.1bp/边（tick 粒度以内）。已按 2026-10-18 用户裁决采用费用制。
