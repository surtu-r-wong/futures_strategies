# M02 本地实现与验证计划

目标：在原单次日盘/日结账户旁路中增加独立 contract-fees-v1 费用配置，保留旧 uniform-bps-v1 计算及版本边界；真实67行仅交未就绪候选，不初始化账户或重算策略。

1. 新增纯费用模块：单位显式换算，按合约/日期选规则；开仓对多空一致，FIFO 日期化净持仓拆普通平仓/平今/反手。日内开仓差异仅按显式批准的开仓后平今调整政策处理；经纪商附加费、滑点、未计项均要求声明。
2. 修改 contracts/engine/store：新配置与 cost_bps 互斥；新状态保存逐手开仓交易日、时点和已收费用证据。旧状态缺日期时阻塞迁移，不猜年龄。计算后费用、净值和保证金一致，重复日结不重复计费。
3. 本地候选适配：读取汇总方既有CSV及JSON，核对67个原生目标不变；映射单日乘数/保证金/交易所费用，未知单位/经纪商/有效期等显式缺项，保留EC独立生命周期缺口。
4. 合成回归：元/手、千分比、万分比，多空开仓、跨日/平今/反手与混合持仓批次，费用后NAV和保证金拒绝，未知/过期规则拒绝，旧bp回归与SQLite幂等。仅临时合成测试账户允许初始化；真实账户始终不动。
5. 交付候选配置、字段说明、测试及手算证据、response.md和本地提交；新引擎指纹拒绝旧账直接混接，不实现真实账户迁移或生产启用。

边界：维持当前单次日盘执行接口。费用/持仓分拆函数可独立验证日内成交，但不借本次添加完整盘中行情/撮合模型。逐合约费规则变更需新版本与显式迁移，不通过引用追加覆写历史费用。未取新数据，未修改原策略或归档目标。
